### 경영 문서 양식 — 작성 후 PDF 저장

화면에서 바로 작성하고 **A4 한 장 PDF**로 저장하는 사내 문서 서식 모음입니다.
설치할 것도, 로그인할 것도 없습니다. 입력 내용은 서버로 전송되지 않습니다.

**[→ 양식 열기](https://philgoose.github.io/nobiliaire/)**

</div>

## 수록 양식 6종

| 양식 | 쓰는 상황 |
|---|---|
| **주간 경영 브리핑** | 부서별 주간보고를 임원용 1장으로 취합. 결정 안건과 리스크를 분리해 표기 |
| **임원 회의록** | 안건 · 논의 · 결정사항 · 실행항목(담당/기한)까지 한 장에 |
| **주간 업무보고** | 부서가 임원에게 제출. 금주 실적 · 차주 계획 · 지원 요청 |
| **프로젝트 진행 현황** | 단계별 진척과 리스크, 지금 결정이 필요한 사항 |
| **거래처 미팅 기록** | 논의 · 합의 · 후속 조치. 작성자 소견란 포함 |
| **업무 인수인계서** | 담당 교체 시 누락 방지. 진행 중인 건과 다음 할 일까지 |

## 사용법

1. 왼쪽에서 양식을 고릅니다
2. 회색 글씨 위를 눌러 바로 입력합니다
3. **PDF로 저장**을 누르고, 인쇄 창에서 대상을 "PDF로 저장"으로 선택합니다
4. 휴대폰은 공유 → 인쇄 → PDF 저장

## 설계 기준

- **모든 양식이 A4 정확히 한 장**입니다. 실제 렌더링으로 페이지 수를 검증했습니다
- 결재란을 넣어 **읽는 문서가 아니라 결재가 도는 문서**로 만들었습니다
- 입력값은 브라우저 안에만 있습니다. 전송·저장되는 곳이 없습니다
- 사내 규정에 맞춰 항목을 수정해 쓰셔도 됩니다

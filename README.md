### 업무 문서 양식 — 작성 후 PDF 저장

상담 · 매칭 · 성혼 관리에 쓰는 사내 서식을 화면에서 바로 작성하고
**A4 한 장 PDF**로 저장합니다. 설치도, 로그인도 없습니다.

**[→ 양식 열기](https://philgoose.github.io/nobiliaire/)**

## 수록 양식 6종

| 양식 | 쓰는 상황 |
|---|---|
| **입회 상담 기록** | 신규 상담 → 희망 조건·가치관 정리 → 플랜 제안까지 한 장 |
| **매칭 제안 검토서** | 제안 전 두 회원 조건 대조, 맞는 지점·우려 지점, 사전 조율 사항 |
| **만남 후 피드백 기록** | 양측 피드백을 표현 그대로 남기고, 어긋난 지점에서 다음 매칭 방향을 잡음 |
| **주간 운영 브리핑** | 상담·입회·매칭·성혼·해지 지표와 컨설턴트별 현황을 임원 1장으로 |
| **VIP 전담 케어 리포트** | 전담 관리 회원의 월간 활동·상태 변화·다음 달 방향 |
| **한일 매칭 진행 현황** | NOBILIAIRE JAPAN 라인의 단계별 현황·현지 일정·조율 사항 |

## 사용법

1. 왼쪽에서 양식을 고릅니다
2. 옅은 글씨 위를 눌러 바로 입력합니다
3. **PDF로 저장** → 인쇄 창에서 대상을 "PDF로 저장"으로 선택
4. 휴대폰은 공유 → 인쇄 → PDF 저장

## 설계 기준

- **6종 전부 A4 정확히 한 장.** 실제 렌더링으로 페이지 수를 검증했습니다
- 결재란을 넣어 **읽는 문서가 아니라 결재가 도는 문서**로 만들었습니다
- 빈칸마다 "무엇을 적어야 하는지"를 안내 문구로 넣었습니다
- 입력값은 브라우저 안에서만 처리됩니다. 전송·저장되는 곳이 없습니다
- 개인정보가 들어가는 양식에는 보관·파기 및 동의 절차 확인 문구를 넣었습니다

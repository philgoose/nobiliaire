진행 방식 — 일차별 산출물로 검수 지점을 고정

1일차업무 1건 선정 → 환경 세팅 → 첫 화면 작동. 종료 시점에 임원별 작동 프로토타입 6개를 눈으로 확인
2일차데이터 연결 · 자동 요약 · 보고서 출력. 당사가 현재 쓰는 보고 양식 그대로 나오도록 조정
3일차공유 · 배포, 그리고 유지·수정 방법 인수. 양식이 바뀌어도 임원이 직접 손볼 수 있는 상태로 종료

기대 효과

  • 임원 1인당 작동하는 업무 도구 1개 확보 (총 6개)
  • 주간보고·결재문서 요약 자동화로 임원 검토 시간 단축
  • 부서별 보고를 가로지르는 교차 분석을 임원이 직접 수행
  • 도구·소스·교안 전부 당사 소유
  • 3일차에 유지·수정 방법 인수 — 외부 의존 없음

리스크 및 대응

  • 사전 지식 → 코딩 불필요. 말로 지시해 제작, 1일차 오전 내 습득
  • 정보보안 → 사내 데이터 외부 반출 없음. 실습은 가상·샘플 데이터, 실데이터는 당사 PC 내에서만 처리
  • 성과 불확실 → 일차별 산출물로 검수 지점 고정. 각 일차 종료 시 결과물을 직접 확인
  • 임원 일정 → 후보일 2개 사전 홀드 후 확정
